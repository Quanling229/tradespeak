# TradeSpeak · 外贸情景英语学习网站

专为 Quinn 定制的文具外贸英语学习平台，聚焦马克笔、荧光笔等产品的真实业务场景。

## 功能模块

- **真实业务场景**：13节系统课，覆盖展会接待、报价谈判、交期沟通、客户开发、样品确认、付款条款、质量投诉、物流跟进、OEM/ODM定制、认证合规、包装陈列、客户维护、视频会议
- **播客磨耳朵**：10期男女双主持互动播客，含真实外贸电话对话
- **AI智能陪练**：每节课6轮真实对话，支持语音/文字输入，智能评分和引导式反馈

## 部署方式

1. Fork 或上传本仓库到 GitHub
2. 进入 Settings → Pages
3. Source 选择 Deploy from a branch，Branch 选择 main，文件夹选择 /(root)
4. 保存后等待1-2分钟，访问 https://Quanling229.github.io/tradespeak/

## 手机端使用

1. 用 Chrome 浏览器打开网站（华为手机不要用自带浏览器）
2. 系统设置 → 辅助功能 → 无障碍 → 文本转语音输出，切换为 Google 文字转语音引擎，下载英文语音包
3. 点击菜单 → 添加到主屏幕，即可像APP一样使用

## 自动更新

课程内容每3天自动更新一次，从全网搜集最新的文具外贸知识，汇总成有体系的学习内容。

## 技术栈

- 纯前端单文件应用（HTML + CSS + JavaScript）
- Web Speech API（语音识别 + 语音合成）
- Service Worker（离线缓存 + 自动更新）
- PWA（支持添加到主屏幕）
- LocalStorage（学习进度本地存储 + 多设备同步）
